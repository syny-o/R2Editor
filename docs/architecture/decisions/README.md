# Architecture decision records

Use this directory for decisions that affect multiple modules or are expensive
to reverse. Create one numbered Markdown file per decision:

```text
0001-use-qstandarditemmodel-for-project-tree.md
0002-keep-project-snapshots-in-json.md
```

Suggested template:

```markdown
# Decision title

Status: proposed | accepted | superseded

## Context

What problem or constraint requires a decision?

## Decision

What approach was selected?

## Consequences

What becomes easier, harder or intentionally unsupported?
```
